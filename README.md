# 操作系统资源与存储管理算法工具集

这是我在操作系统课程实践中整理的算法项目。我用 Java Swing 展示银行家算法的资源分配过程，并用 C 实现动态分区管理和页面置换。整理仓库时，我把算法逻辑、演示界面和测试尽量分开，方便自己复习，也方便别人直接运行。

## 我做了什么

| 模块 | 实现内容 | 我重点理解的问题 |
| --- | --- | --- |
| 银行家算法（Java / Swing） | 计算安全序列，演示资源请求的试探分配、检查与回退 | “安全状态”是存在完成顺序，不等于当前所有进程都能立刻完成 |
| 动态分区管理（C） | 首次适应、最佳适应、最差适应；分配、回收及相邻空闲块合并 | 三种策略如何选择空闲块，以及碎片如何产生 |
| 页面置换（C） | FIFO、LRU、OPT，统计缺页次数与命中率 | 三种策略分别依据什么信息淘汰页面 |

我在整理原课程代码时补齐了最差适应策略，修正首次适应成功路径的问题，并为关键算法加入可重复运行的测试。Swing 界面中的等待图环检测是单独的演示功能，不把它与银行家算法的安全性检查混为一谈。

## 运行与验证

环境：GCC、Make、JDK 17 或更新版本。

```bash
make test
```

分别运行三个模块：

```bash
./build/page_replacement 3
./build/partition_allocation best
java -cp build/java BankersVisualizer
```

`make test` 会检查银行家算法的安全序列、页面置换的已知结果，以及动态分区分配与回收后的状态。项目是教学实现，不涉及真实内核的并发调度、硬件页表或内存保护。
