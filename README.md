# 操作系统资源与存储管理算法工具集

课程实践项目，包含三个可独立运行的模块：

- Java Swing 银行家算法可视化：随机生成安全状态，演示请求试探分配、回退、资源释放和等待图环检测。
- C 动态分区管理：实现首次适应、最佳适应、最差适应，支持分配、回收与相邻空闲块合并。
- C 页面置换：实现 FIFO、LRU、OPT，输出缺页次数与命中率。

本仓库在原课程代码基础上完成可测试化整理，补全了最差适应算法，并修正原首次适应成功路径不可达的问题。

## 构建与测试

需要 GCC、Make 和 JDK 17+：

```bash
make test
```

也可以分别运行：

```bash
./build/page_replacement 3
./build/partition_allocation best
java -cp build/java BankersVisualizer
```

`make test` 会验证经典银行家算法安全序列、三种页面置换的已知结果，以及三种动态分区策略的分配/回收不变量。

## 项目边界

这是用于理解操作系统基础算法的教学项目，不模拟真实内核的并发、页表硬件或内存保护机制。图形界面中的死锁环检测是等待图演示，与银行家算法的安全状态判断分开呈现。
